# Offerables Sold Overlay (Boards 48+)

Visual **SOLD** marks on Offerables board photos from the Thursday shipping ledger.

**Not** part of CTR prep or pricing. Office helper only — compare to physical boards, pull sold pins, then clone remaining inventory in Whatnot.

## URL

https://finsandpins.github.io/ClickToClaim/Offerables15/sold-overlay/

## Data

- Boards: `boards/` (from `Offerables15_Boards48plus/boards_ctr`, Board 48 = first photo)
- Marks: `sold.json` built from ledger rows titled `Board N Pin M` (cancelled excluded)

Rebuild script (Cursor Projects):

`Offerables15_Boards48plus/tools/build_sold_overlay_data.py`

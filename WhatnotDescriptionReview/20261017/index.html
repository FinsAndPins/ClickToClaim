How a line is built

Character and movie always stay. Extra words come only from the listing that was accepted. Makers and set words start on. Edition counts and chaser start off. Shipping, you choose, authenticity hype, New, and Used are not added. New and Used stay only when they are part of the character or movie name, as in The Emperor's New Groove. Hand-priced pins are not in this list, because that stored title is the listing that was not accepted. Today's Whatnot file is unchanged.
